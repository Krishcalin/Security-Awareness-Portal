Narration bench

A reported fault — the first word after a full stop is not heard — is an audio problem, and audio cannot be verified by reading code or by looking at a screenshot. This page plays the same passage several ways so it can be settled by listening. Play them in order and note which ones are clean; the winner becomes how the portal speaks.
